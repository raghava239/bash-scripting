## 5. Study method

For each subject, follow this cycle:

1.  **Understand:** Learn the concept from first principles.
2.  **Examples:** Review practical commands and scenarios.
3.  **Practice:** Write the query or code yourself.
4.  **Correction:** Review mistakes and understand the correction.
5.  **Interview:** Explain the concept and solve a scenario aloud.

Do not move on from SQL basics until you can independently write the
basic queries. For Bash, prioritize practical server and log-analysis
examples.
